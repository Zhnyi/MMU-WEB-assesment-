[What I learned independently]

Independently, I have learnt many many things regarding coding in html and css. A lot of concepts used to build this website is outside of teached syllabus.

For example, I wanted to center the images and the APA citation under it, I have used display: flex; and justify-content: center;. But I found out independently that, justifying content towards the center includes all characters of the citation under it, making each character adjacent to each other with no spacing between them. As an example, justifying content to the center turns "text sentence 2" into "textsentence2", everything is aligned towards the center. This was a problem initially because I wanted to align them all towards the center, but I later gave up the idea and leave it aligned to the left.

I have also learnt display:flex and display: block. Flex is to make children elements of one major element to be arranged side by side horizontally. Whereas, display: block is needed to solve for certain elements that are arranged side-by-side by default, in other terms elements that are inline-block by default, like the [form] element or [a] element (links). This is an incredible discovery because I actually feel like I've learnt something really important about html design

Another thing I have learnt independently is how to apply APA 7th generation citations into the website. I've learnt to use the figure semantic and figcaptions as the APA titie. Also discovered what inlines, and blocks are from simply making citations. I understood that the element [em] is an inline, meaning it exists within an existing text, like a word in a sentence. a block means it exists as a block, a paragraph. If an element block is in an element block, there will be two separated texts (separated horizontally), assuming both blocks each are a single paragraph text.

Next, I've also understood that most common elements have their own default categories. For example, I can change the [p] (paragraph) element from its default category [Block] into [Inline] by writing p { display: inline; } into CSS code, which would make it function similarly with [em] element.

In addition, I have also learnt about flex-wrap: wrap; CSS code. This code is important for when the user decides to collapse the page, flex-wrapping an element, especially an element that is arranged side by side, will adjust and arrange itself according to the collapsed size of the page, making the page remain fully function regardless page sizing. Flex: 1; is also used in the sizing of the cards.

I have also learnt to use sticky navigation, had it set up for all page's local and website-wide navigation.

Finally, I have learnt that writing html and css code is no joke.

[Why computer hardware is an important topic]

Hardware is the layer everything else depends on. Software, operating systems, and networks all run on physical components. Without computer hardware, having software, OS, and networks, will be pointless.

It is also important in knowing what kinds of computer hardware is needed for what kinds of context , for example, giving every employee a high-specification computer wastes money, while giving all departments a low-specification computer slows its work down. Knowing what each component does is what allows that decision to be made properly instead of by guessing. Learning about computer hardware can help with making better financial choices in purchasing computers in a company or for individuals.

[Five credible lifelong-learning resources]

The five resources below were chosen because each one supports a different kind of learning: an official standard, free structured video training, formal courses, a practical tool, and current industry news.

1. CompTIA

Visit CompTIA

  • What can be learned: Entry-level IT hardware knowledge, including components, assembly, and troubleshooting, through the CompTIA A+ certification.
  • Why it is useful: It is an official certification body rather than an individual publisher, so the content is standardised and recognised by employers.
  • How it supports future learning: It sets out a clear progression from A+ to Network+ and further certifications, so there is a defined next step instead of guessing what to study.

2. Professor Messer

Visit Professor Messer

  • What can be learned: Free video training covering the CompTIA A+ hardware topics, including processors, memory, motherboards, power supplies, cooling, and expansion cards.
  • Why it is useful: It follows the official certification objectives closely but costs nothing, which makes it accessible to a student without a training budget.
  • How it supports future learning: It allows the same components covered on this website to be studied at a deeper level, and prepares a learner for the certification itself.

3. Coursera

Visit Coursera

  • What can be learned: Structured courses from universities and technology companies, including IT support programmes that begin with computer hardware before moving into operating systems and networking.
  • Why it is useful: Courses are organised into graded modules with deadlines, which suits learners who struggle to stay consistent with unstructured self-study.
  • How it supports future learning: Completed courses produce a certificate that can be shown to an employer, and the platform covers adjacent topics such as networking and cloud computing for later.

4. PCPartPicker

Visit PCPartPicker

  • What can be learned: How real components fit together, including motherboard and processor compatibility, power supply wattage requirements, and current pricing.
  • Why it is useful: It warns about incompatible combinations automatically, which turns compatibility from an abstract concept into something that can be tested immediately.
  • How it supports future learning: It allows a full system to be planned within a budget without spending anything, which is practice for making real purchasing decisions later.

5. Tom's Hardware

Visit Tom's Hardware

  • What can be learned: Current news, reviews, and performance testing for processors, graphics cards, storage devices, and cooling systems.
  • Why it is useful: Hardware models change constantly, and this is a long-established publication that tests components rather than repeating manufacturer claims.
  • How it supports future learning: Reading it regularly keeps knowledge of current components up to date, which textbooks and certification syllabuses cannot do on their own.
