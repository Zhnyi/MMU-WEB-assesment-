Computer Hardware

Introduction to Computer Hardware

Hello and welcome to my website about computer hardware. This website will provide useful information about computer hardware in several forms.

Overview

Computer hardware covers input devices, output devices, system units, storage device, and communication device. This website focuses specifically on the internal hardware inside the system unit (the physical components inside a chasis called system unit) ,the input devices (keyboard, etc.), and output devices (monitor, etc) used to complete the full desktop setup for individuals.
